# Kidney tubuloid cyst-induction image intake

ResearchDesk lists this source record as an image inventory. The associated
article describes human adult-stem-cell-derived kidney tubuloids and QuPath
measurements of cysts after forskolin or vehicle treatment. Its Figure 4 image
archive is available from the [Bonn Data record](https://doi.org/10.60507/FK2/OM25XQ)
under CC BY 4.0. The archive is not copied into this repository.

The local organoid-phenotyping importer verified the repository-pinned archive
checksum and indexed 280 TIFF images. Those images remain pending annotation:
the archive supplies no instance masks, and the filenames do not identify
individual tracked tubuloids. The A/B/C labels are source technical replicates.
The source article reports object tracking, but the source images in this intake
do not include those track identities or measured values. The source kidney
identifier is therefore used to keep related acquisitions in one frozen split;
it is not treated here as a verified donor identifier.

ResearchDesk's 1.3 manifest records the cyst morphology analysis as unavailable
until reviewed masks and, for longitudinal results, an object-to-track map are
provided. This record contains no segmentation score, cyst-size result, kidney
function endpoint, or rejuvenation claim.
