# iPS-PDL RNA-seq metadata audit and exploratory analysis

This audit checks the archive metadata for the RNA-seq dataset cited by Taniguchi et al. (2026). Its associated [exploratory expression analysis](IPSPDL_RNASEQ_EXPLORATORY_RESULTS.md) uses deposited reads and reports descriptive summaries only. The live DDBJ Search API lists BioProject [PRJDB39888](https://ddbj.nig.ac.jp/search/entry/bioproject/PRJDB39888), and its project description says three independent samples per cell type were examined. The [DDBJ API documentation](https://github.com/ddbj/ddbj-search-api) describes record lookup through `/search/api/entries/{type}/{accession}`. The reproducible fetch script, [sample manifest](ipspdl_rnaseq_manifest.tsv), [BioSample index](ipspdl_rnaseq_biosample_index.tsv), and hash receipt are included with this review.

## What the archive establishes

The audit retrieved 37 public metadata records: one BioProject, nine SRA runs, nine experiments and 18 linked BioSamples. The nine cited runs map to three samples each labeled iPS-PDL, iPS and primary PDL. The experiment records specify transcriptomic RNA-seq, poly-A mRNA selection and NovaSeq 6000. Eight run records specify paired layout; DRR913336 is single or layout-unspecified. The DDBJ FASTQ directory listings contain 17 compressed files totaling 15,976,782,817 bytes (about 15.98 GB) by HTTP HEAD `Content-Length` on 2026-10-10; see the [file inventory](ipspdl_rnaseq_fastq_inventory.tsv). All 17 files were downloaded and hash-checked against the recorded archive checksums before exploratory quantification.

The 18 BioSample links are two records for each of nine sample labels. For every label, the older BioSample has the same Owner, Model and Attribute fields as its newer counterpart; the three older iPS-PDL titles contain the `iPS-DPL` transposition. Only the newer SAMD01828844–SAMD01828852 records are referenced by the nine cited experiments/runs. The older SAMD01787982–SAMD01787990 records have no run among DRR913328–DRR913336. They therefore do not constitute nine additional sequenced samples in this dataset.

The iPS and iPS-PDL sample records all list age 29, female sex and the same 2024-06-11 collection date. The iPS records name RIKEN BRC as provider but give only the generic cell-line value “human iPS cell line”; the iPS-PDL records give the generic “iPS-PDL cell” value and say the cells were cultured with PDL conditioned medium. The archive itself does not identify the parental iPSC line or map each iPS-PDL run to a conditioned-medium donor. The associated publications add important context: [Li et al. (2026)](https://www.jstage.jst.go.jp/article/dmj/advpub/0/advpub_2025-235/_pdf) report one HPS0381 iPSC line differentiated with conditioned media from three different PDL sources, yielding iPS-PDL#1–3, and [Taniguchi et al. (2026)](https://www.frontiersin.org/journals/cell-and-developmental-biology/articles/10.3389/fcell.2026.1821829/full) describe three independently differentiated iPS-PDL lines. The PRJDB39888 labels iPS_PDL1–3 align numerically with those published labels, but the accession records do not explicitly map runs to PDL donor or differentiation source. This is a cross-source linkage, not direct run-level metadata. The published design supports three differentiation products from one parental line, not three independent iPSC donors.

The primary PDL records list Lonza as provider and three ages (18, 24 and 44 years), with two female and one male sample. Thus the primary PDL observations are donor-diverse in age/sex metadata, while iPS/iPS-PDL source metadata are all the same age/sex and omit line identity. A cell-type contrast is consequently entangled with source and donor metadata. All nine BioSamples report “not tested” for karyotype.

## Implication for the regeneration question

The accession supports the claim that the study compared three labeled sample types with three run-linked samples apiece. The associated papers describe three independently differentiated iPS-PDL products from one HPS0381 parental iPSC line using media from three PDL sources; this clarifies the design at the publication level, while run-to-source matching remains unavailable in DDBJ. The three iPS-PDL replicates are therefore not three independent parental iPSC donors. That distinction matters when interpreting both the EV paper and the exploratory RNA-seq summaries.

This dataset supports a descriptive expression comparison with sample-level metadata retained and the single/layout-unspecified run handled separately. It cannot establish independent-line generalization, mature PDL identity, EV cargo causality, oriented insertion, load transfer or a safer cell product. Expression differences are hypothesis-generating and should not be reported as inferential differential-expression results.
