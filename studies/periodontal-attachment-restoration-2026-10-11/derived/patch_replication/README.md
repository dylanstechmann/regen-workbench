# Source-derived additional-specimen transport outputs

All JSON, TSV and SVG outputs here and in `M3_88/` and `M3_90/` derive from:

- Le Luyer M., Coquerelle M., Rottier S., Bayle P. (2016), **M3#88,
  GLN04-289B-URM2**, [DOI 10.18563/m3.sf.88](https://doi.org/10.18563/m3.sf.88).
- The same authors (2016), **M3#90, GLN05-292-URM2**,
  [DOI 10.18563/m3.sf.90](https://doi.org/10.18563/m3.sf.90).

Associated dataset: [DOI 10.18563/m3.2.1.e1](https://doi.org/10.18563/m3.2.1.e1).
Primary study: [DOI 10.1371/journal.pone.0159688](https://doi.org/10.1371/journal.pone.0159688).
We acknowledge **Osteotheque de Pessac, Universite de Bordeaux, France** and
curator **Dr Stephane Rottier**.

[Creative Commons Attribution-NonCommercial 4.0 International](https://creativecommons.org/licenses/by-nc/4.0/).
Generic code is separate from this data license. Retain item-readme citation,
acknowledgment and curator-notification terms for any future scientific article.
No external message or journal submission occurred here.

Changes: source poses applied, mesh audits recorded, artificial triangle
omissions made, four unchanged pilot methods fitted, withheld vertical
top-envelope heights scored, fixed central-patch maps generated. Raw source
meshes are not redistributed. These outputs do not show biological repair.

`frozen_intake.json` and each `plan.json` were saved before new patch outcomes.
`prediction_receipts.json` records coefficients and support/query/prediction
hashes before reference scoring. `patch_summary.json` links plan and prediction
receipt hashes. `transport_summary.json` links the frozen intake hash.
Text hashing uses canonical UTF-8/LF, including plans read from Windows.

See the [report](../../TOOTH_PATCH_TRANSPORT_REPORT.md) for results and limits.
