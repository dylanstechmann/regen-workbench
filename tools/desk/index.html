Run another offline model analysis

From the shared workspace, run wombmodels simulate in the sibling project, then use wombmodels identifiability-report with that run's configuration and trajectory. Use wombmodels design-sweep to compare seeded dimensionless cadence/noise scenarios, a monitor-fault-removed profile when configured faults exist, and reflected event timing when the source has outages or monitor faults. Use wombmodels verify-transport --config examples/transport_fixture.json --out artifacts/transport-verification-v1 to check forward-Euler step refinement against a closed-form dimensionless reference; use wombmodels verify-transport-matrix --config examples/transport_fixture.json --out artifacts/transport-matrix-v1 for seven deterministic dimensionless rate regimes. Use wombmodels verify-mechanics --config examples/mechanics_fixture.json --out artifacts/mechanics-verification-v1 for piecewise-load mechanics checks. Reflected timing preserves event durations and is a fixture sensitivity case, not a realistic outage distribution. Give every output a new directory under its ignored artifacts/ folder.
